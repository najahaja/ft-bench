## Locked decisions

- **Model:** `meta-llama/Llama-3.2-3B-Instruct`
- **Dataset:** `AmazonScience/massive`, config `en-US`, OFFICIAL splits only.
  Do not create a custom split. Do not use Bitext or any other dataset.
- **License:** CC-BY-4.0
- **Task:** constrained NLU parsing — utterance -> {"intent": ..., "slots": {...}}
  - `intent`: one of 60 labels, extracted programmatically from the dataset
  - `slots`: keys from 55 slot types, extracted programmatically from the dataset
  - There is no TicketAnalysis schema, no categories, no sentiments, no
    priorities field anywhere in this project. If you find code referencing
    those, it is leftover from an incorrect earlier build and must be removed.
- **Quantization tool:** `llm-compressor` for AWQ. NOT AutoAWQ (archived
  May 2025) and NOT any package literally named `autoawq`.
- **Prompting:** built exclusively via `tokenizer.apply_chat_template()`.
  No hand-written Llama3 template or ChatML template string literals
  anywhere in the codebase.
- **Benchmark concurrency sweep:** [1, 2, 4, 8, 16]. Not [1, 5, 10, 25, 50].
- **Compute:** Kaggle free T4, fp16, single GPU, no tensor parallelism. $0 budget.
- **Experiment tracking:** Weights & Biases free tier.

## Why MASSIVE, not Bitext (final — do not re-open)

Bitext's customer-support dataset is synthetically generated by Bitext's own
NLG/data-labeling tooling — not independently human-annotated. MASSIVE is
human-annotated, localized from SLURP (Bastianelli et al. 2020), published at
LREC 2022 by Amazon Science. A defensible ground-truth source was a hard
requirement of this project from the beginning. This decision was made once,
reverted to once already after a build deviation, and is now final.
